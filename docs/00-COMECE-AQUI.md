# Comece aqui

Se você abriu o repositório e não sabe o que fazer, leia esta página até o fim.
Ela tem cinco minutos.

## O que é isso

Uma atividade final. Você vai construir um painel de tarefas de mutirão
comunitário usando **só** o que viu nas onze aulas. Nada de novo. Nada a menos.

## O que é diferente das outras atividades

Nas aulas, o código estava na apostila e você digitava. Aqui, doze detalhes
específicos **não estão** na apostila de propósito, e você precisa achá-los na
documentação oficial. Isso é a parte principal da atividade, não um extra.

Procurar na documentação é uma habilidade, e habilidade se aprende praticando
com desconforto. O desconforto é o método, não um defeito do enunciado.

## Ordem de leitura

1. `ATIVIDADE.md` — inteiro, sem pular. Os critérios de aceite são a régua.
2. `docs/01-GUIA-DE-ETAPAS.md` — o que fazer em cada etapa
3. `docs/02-ONDE-PROCURAR.md` — só quando bater uma dúvida específica
4. `docs/04-PROTOCOLO-DE-DEPURACAO.md` — **antes** de pedir ajuda a alguém

## Ordem de trabalho

Faça **uma etapa por vez** e comite ao fim de cada uma. Não tente fazer tudo e
testar no fim: o primeiro erro vai se esconder atrás de outros cinco.

A ordem E1 → E7 não é sugestão. Cada etapa depende da anterior funcionando.

## Se você está completamente perdido

Isso acontece e não significa nada sobre você. Faça o seguinte, na ordem:

1. Rode `npm install` e `npm run dev`. Se a página abrir, você já venceu a E1.
2. Abra o seu repositório `my-daily-habits`. Ele tem a forma geral de tudo aqui.
3. Escolha **a menor coisa possível**: fazer um cartão de tarefa aparecer na tela
   com o título escrito na mão. Só isso. Comite.
4. Agora faça três cartões com `map()`. Comite.
5. Continue assim. Uma coisa pequena, testada, comitada.

Ninguém constrói isto de uma vez. Todo mundo constrói assim, inclusive quem faz
isso por profissão.

## Se você travou de verdade

Abra uma **issue** neste repositório usando o modelo "Dúvida técnica". O modelo
pede exatamente o que o professor precisa para te ajudar em uma resposta em vez
de cinco. Preencher o modelo com atenção resolve boa parte das dúvidas sozinho.
